Fungsi

Mengubah nama file PDF secara otomatis berdasarkan Nomor Referensi yang terdapat di dalam dokumen Faktur Pajak

Cara Penggunaan

Buka folder PDF
Masukkan seluruh file Faktur Pajak PDF yang ingin di-rename
Kembali ke folder utama
Klik kanan Bulk-Rename-Faktur.command
Pilih Open
Tunggu sampai proses selesai
Periksa hasil rename di folder PDF

Persyaratan

macOS
Python 3
Koneksi internet untuk instalasi awal PyMuPDF

Format Nama File

Contoh:

Nomor Referensi: 139/SP-BB/260701

Hasil:
139SP-BB260701.pdf

Catatan

File yang tidak memiliki Nomor Referensi akan dilewati
File dengan nama tujuan yang sudah tersedia tidak akan ditimpa
File PDF asli diproses langsung di dalam folder PDF
